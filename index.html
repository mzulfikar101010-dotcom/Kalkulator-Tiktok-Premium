Gambar produk
Menyusun gambar semua barang di Isi Paket jadi satu foto piramida. Susunan ikut tersimpan saat paket disimpan ke database.
Ketuk barang untuk memilih, lalu geser dengan jari atau pakai tombol di bawah. “Geser semua” menggeser seluruh barang sekaligus; tahan tombolnya untuk geser terus.
Simpan membuat file Excel. Simpan ke database menyimpan paket (isi, harga, dan susunan gambar) secara online; buka lagi lewat ikon Database paket di atas. Simpan gambar saja hanya menyimpan gambar susunan. Impor Excel tetap bisa dipakai untuk file lama. Komisi afiliasi dan pre order mengikuti Pengaturan.
